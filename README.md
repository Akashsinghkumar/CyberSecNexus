# CyberSec Nexus – AI-Assisted SOC Platform

CyberSec Nexus is a production-style cybersecurity project implementing
an integrated Intrusion Detection System (IDS) and Intrusion Prevention
System (IPS) with AI-based threat explanation and SOC dashboards.

## Core Features
- Real-time IDS monitoring
- Automatic IPS IP blocking
- Explainable AI assistance
- Executive SOC dashboard
- Blocked IP Intelligence dashboard

## Architecture
Modular architecture with separate IDS, IPS, AI, Database, and UI layers.
